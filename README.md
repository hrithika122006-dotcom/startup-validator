
# Startup Validator

AI-Powered Startup Idea Validator built with Next.js, TypeScript, Supabase, and Groq AI.

## Features
- AI-powered startup idea evaluation
- Market size, competition, feasibility & business model scoring
- User authentication
- Saved evaluation history

## Tech Stack
- Next.js 16
- TypeScript
- Tailwind CSS
- Supabase (Database + Auth)
- Groq AI

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
